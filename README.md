# Hexatech

## Sobre o projeto

A Hexatech é uma plataforma web conceitual voltada à gestão de lojas de hardware e eletrônicos. Seu objetivo é apresentar uma solução para organizar informações de estoque, vendas, movimentações e auditoria em uma interface centralizada.

## Funcionalidades apresentadas

- Painel visual de gestão.
- Controle e acompanhamento de estoque.
- Histórico de movimentações.
- Apresentação de recursos de trocas e devoluções.
- Tela de acesso com perfis de operador e administrador.

**Observação:** a disponibilidade dessas funcionalidades depende da implementação efetiva no código do projeto.
